## 📌 Project: Mood Tracker

A simple and interactive React app that allows users to track their mood.

### ✨ Features

* 🎭 Select different moods (Happy, Sad, Angry, Calm)
* 🎨 Dynamic UI updates based on mood
* ⚡ Built using React Hooks (`useState`)
* 📱 Responsive and clean UI
